# 🚀 RB Script - TRL Dashboard

سكربت احترافي ومتكامل لروبلوكس يعمل على جميع الـ Executors (الموبايل والكمبيوتر)، مدعوم بنظام مفاتيح (Key System) آمن وموقع إلكتروني لتوليد الأكواد.

---

## 💻 كود التشغيل السريع (Execute Loadstring)

```lua
loadstring(game:HttpGet("[https://raw.githubusercontent.com/Jaddevhere/rb-script/main/main.lua](https://raw.githubusercontent.com/Jaddevhere/rb-script/main/main.lua)"))()
